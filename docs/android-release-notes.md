Actualización de DawerTech para Android

- Corregida la lectura del tamaño del APK que impedía descargar actualizaciones con el mensaje «Los datos de la actualizacion no son validos».
- Errores de actualización diferenciados y registrados con códigos para facilitar el diagnóstico por ADB.
- Prueba de regresión del puente de Capacitor ejecutada antes de publicar el APK.

Para recibir esta corrección desde una versión afectada, descarga el APK desde la web y abre el archivo para instalarlo sobre la release anterior. No desinstales la app: con la misma firma conserva sus datos y sesión. Android solicitará autorizar la instalación desde el navegador si todavía no tiene ese permiso. Después de instalar esta corrección, las siguientes actualizaciones podrán descargarse dentro de la app. Un APK debug firmado con otra clave no admite actualizarse directamente con este release.
