Actualización de DawerTech para Android

- Descarga de actualizaciones dentro de Android con porcentaje, barra de progreso y apertura del instalador al completar la descarga.
- Descarga del APK desde la web con progreso, cancelación y verificación del archivo.
- Botón del login simplificado a Descargar APK.

Instala el APK sobre la versión release anterior, firmada con la misma clave, para conservar los datos y la sesión. Android solicitará autorizar la instalación desde el navegador si todavía no tiene ese permiso. Un APK debug firmado con otra clave no admite actualizarse directamente con este release.
